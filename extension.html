Budgétable

Installer l’extension Budgétable

Version 1.0.0 · ordinateur uniquement, navigateur Chrome ou Edge · gratuite

À quoi elle sert : votre liste de courses Budgétable vous suit sur le site de votre drive (E.Leclerc, Carrefour, Auchan, Intermarché, Courses U). Un panneau vous montre, article par article, les produits correspondants les moins chers affichés ; vous ajoutez au panier d’un clic. Elle compare aussi les prix relevés entre vos drives. Rien n’est envoyé ailleurs : tout reste sur votre ordinateur.

Télécharger l’extension (fichier .zip, 27 Ko)

Bientôt sur le Chrome Web Store et Microsoft Edge Add-ons : l’installation se fera alors en un clic, sans les étapes ci-dessous.

Installation, en 2 minutes

  1. Décompressez le fichier téléchargé : clic droit sur budgetable-extension.zip › « Extraire tout… ». Vous obtenez un dossier budgetable-extension. Gardez-le (par exemple dans Documents) : Chrome en a besoin.
  2. Dans Chrome, tapez chrome://extensions dans la barre d’adresse (dans Edge : edge://extensions).
  3. Activez le Mode développeur (interrupteur en haut à droite ; dans Edge, à gauche).
  4. Cliquez sur Charger l’extension non empaquetée et choisissez le dossier budgetable-extension (celui qui contient le fichier manifest.json).
  5. La carte « Budgétable – courses en drive » apparaît, en version 1.0.0. Épinglez-la : icône puzzle en haut à droite › épingle à côté de Budgétable.
  6. Rechargez la page Budgétable si elle était ouverte.

Utilisation

  1. Sur Budgétable, onglet Courses : cliquez sur Envoyer vers l’extension. Le message « Liste envoyée à l’extension » confirme.
  2. Ouvrez le site de votre drive dans le même navigateur, connectez-vous et choisissez votre magasin.
  3. Le panneau vert Budgétable apparaît en bas à droite avec votre liste. Pour chaque article : « Chercher », puis « Ajouter au panier » sur le produit qui vous convient.
  4. Vérifiez votre panier et validez la commande sur le site du drive, comme d’habitude.

Mettre à jour

Téléchargez la nouvelle version, remplacez le contenu du dossier budgetable-extension, puis cliquez sur la flèche circulaire « Actualiser » de la carte Budgétable dans chrome://extensions.

Ça ne marche pas ?

  • « Extension non détectée » sur Budgétable : vérifiez que la carte Budgétable est activée et en version 1.0.0 (ou plus) dans chrome://extensions, puis rechargez la page Budgétable. L’envoi direct fonctionne depuis budgetable.onrender.com.
  • Pas de panneau sur le drive : rechargez la page du drive ; vérifiez que l’adresse est bien celle d’un drive pris en charge.
  • Sur téléphone : les extensions ne fonctionnent pas sur Chrome mobile. Utilisez les boutons de recherche par drive de l’onglet Courses.

Chrome peut afficher au démarrage un message sur les extensions en mode développeur : c’est normal tant que l’extension n’est pas publiée sur le Chrome Web Store (prévu).
